# Исследование данных COVID. Подготовка к визуализации в Tableau

EDA глобальной статистики по COVID. 
Цель: проанализировать уровень заражения, процент смертности и прогресс вакцинации. 

## Стек технологий
*   PostgreSQL
*   DBeaver

## Ключевые навыки
*   **Агрегация и расчёт метрик** 
*   **Оконные функции** `SUM() OVER (PARTITION BY ...)` для расчета накопительного итога (Running Total).
*   **CTE** для расчета на основе результатов оконных функций.
*   **Витрина данных** для быстрой визуализации в Tableau.
*   **View** для обновления витрины без повторного написания запросов.
