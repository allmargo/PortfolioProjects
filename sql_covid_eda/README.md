# Исследование данных COVID-19 и подготовка к визуализации

Данный проект посвящен разведочному анализу данных (EDA) глобальной статистики по COVID-19. 
Цель — проанализировать уровень заражения, процент смертности и прогресс вакцинации. 
В рамках проекта создается витрина данных для быстрого подключения к Tableau, а также представление для удобного доступа к актуальной аналитике без повторного написания сложных запросов.

## Стек технологий
*   PostgreSQL (SQL)
*   DBeaver

## Ключевые навыки
*   **Очистка данных**
*   **Агрегация и подсчёт** 
*   **Оконные функции** `SUM() OVER (PARTITION BY ...)` для расчета накопительного итога вакцинированных по странам.
*   **CTE** для упрощения сложных запросов и расчета процентов на основе результатов оконных функций.
*   **Витрины данных и Представления**

## Результаты
*   Рассчитан глобальный процент смертности
*   Выявлены страны с самым высоким уровнем заражения по отношению к их населению
*   Проанализирован прогресс вакцинации путем расчета накопительного процента вакцинированного населения с течением времени
