# Анализ корреляций в киноиндустрии

Цель: выявить факторы (бюджет, оценка, студия) имеющие наибольшую корреляцию с кассовыми сборами (gross).

## Стек технологий
*   Python 3
*   Pandas, NumPy, Matplotlib, Seaborn

## Ключевые навыки
*   **Очистка данных:** Обработка пропущенных значений, проверка типов данных, поиск дубликатов.
*   Логарифмирование (`np.log1p`) для борьбы с сильными выбросами, чтобы увидеть закономерности.
*   **Визуализация:** Построение графиков регрессии, "ящиков с усами" (boxplot), диаграмм рассеяния (scatter) и тепловых карт (heatmap).
*   **Корреляционный анализ:** Расчет корреляции Пирсона, Кендалла и Спирмена. Использование `factorize()` для включения категориальных признаков в матрицу корреляций.
