### Мои проекты

### 1. [Анализ корреляций в киноиндустрии (Python)](./python_movie_correlation)
*Задача:* Выявить факторы, имеющие наибольшую корреляцию с кассовыми сборами.  
*Стек:* `Python` `Pandas` `NumPy` `Matplotlib` `Seaborn` `Jupyter Notebook / Google Colab`  
*Навыки:* 
*   **Data Cleaning, Feature Engineering**
*   **Логарифмирование** (`np.log1p`) для борьбы с сильными выбросами, чтобы увидеть закономерности
*   **Построение графиков** регрессии, ящиков с усами, диаграмм рассеяния и тепловых карт
*   **Расчет корреляции** Пирсона, Кендалла и Спирмена
*   Использование `factorize()` для включения категориальных признаков в матрицу корреляций

### 2. [Очистка данных датасета Nashville Housing (SQL)](./sql_Nashville_Housing_cleaned_data)
*Задача:* Преобразовать датасет для EDA.  
*Стек:* `PostgreSQL` `DBeaver`  
*Навыки:*  
*   **DDL** (`ALTER TABLE`, `ADD COLUMN`, `DROP COLUMN`)
*   **self-join** для заполнения пустых значений

### 3. [Исследование данных COVID. Подготовка к визуализации в Tableau (SQL)](./sql_covid_eda)
*Задача:* EDA глобальной статистики по COVID: уровень заражения, смертность и прогресс вакцинации.  
*Стек:* `PostgreSQL` `DBeaver`  
*Навыки:*  
*   Агрегация и расчёт метрик
