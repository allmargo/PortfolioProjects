# Очистка данных датасета Nashville Housing

**Цель:** Преобразовать исходный датасет для проведения EDA.

## Стек технологий
*   **PostgreSQL (SQL)**
*   **DBeaver**

## Ключевые навыки
*   DDL (`ALTER TABLE`, `ADD COLUMN`, `DROP COLUMN`)
*   self-join для заполнения пустых значений
*   строковые функции (`SUBSTRING`, `POSITION`, `SPLIT_PART`)
*   оконные функции (`ROW_NUMBER() OVER PARTITION BY`)
*   CTE
*   условная логика (`CASE WHEN`)
*   обработка пропусков (`IS NULL`, `COALESCE`)
